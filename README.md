## 🎮 PRESS START

Open `index.html` in any modern browser. That's it. No build step, no frameworks, no installs.

```bash
git clone https://github.com/niharkocheand/<your-repo-name>.git
cd <your-repo-name>
# then just open index.html (or use a local server)
python -m http.server 8000   # optional → http://localhost:8000
```

> 💡 Replace `<your-repo-name>` with the name of this repository.

## 🎨 CUSTOMIZE YOUR OWN PLAYER

| Typing roles | The `roles` array in `script.js` |

## 🌐 DEPLOY FOR FREE (GITHUB PAGES)

1. Push these files to the root of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Your site goes live at `https://niharkocheand.github.io/<your-repo-name>/`.
